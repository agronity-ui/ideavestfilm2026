Executive Summary

Smart Irrigation System

by Ahmad Nafis Al Adieb

Market Potential

Industri irigasi pintar diproyeksikan mencapai $2.1B pada 2028. Target utama kami adalah lahan perkebunan sawit dan pertanian hortikultura di area tropis yang sering mengalami fluktuasi cuaca ekstrem.

Teknologi Utama (Methodology)

Menggunakan ESP32 yang terhubung dengan sensor Capacitive Soil Moisture, dikombinasikan dengan API prakiraan cuaca BMKG. Data diolah dengan algoritma Machine Learning Regresi Linear untuk menentukan durasi penyiraman optimal secara presisi.

Kebutuhan Dana Pendanaan

Total dana yang dibutuhkan adalah Rp 45.000.000 untuk prototyping perangkat keras tahap akhir, lisensi server cloud selama 1 tahun, dan uji lapangan di 3 titik kebun percobaan institusi.
